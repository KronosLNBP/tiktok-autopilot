Autopilot Videos

Autopilot Videos is a personal, open-source tool that creates short vertical text-animation videos and uploads them to the operator's own TikTok account.

How it works

  1. The account owner signs in with Login with TikTok and authorizes the app.
  2. Short video scripts are kept in a content queue in a private GitHub repository.
  3. A scheduled job renders each script into a 1080×1920 MP4 video.
  4. The video is sent to the owner's TikTok inbox as a draft (Content Posting API, video.upload), or published directly with the privacy level the owner selects (video.publish).
  5. The upload status is saved to a log so the owner can track what was posted.

The app only accesses the account of the person who authorizes it. It does not access other users' data.
