Privacy Policy

Last updated: November 10, 2026

Data we access

When you sign in with TikTok we receive: your basic profile information (user.info.basic: open ID, display name, avatar) and OAuth access/refresh tokens that allow uploading videos (video.upload, video.publish).

How we use it

Only to upload videos you created with this tool to your own account and to check their upload status. We do not sell, share, or use your data for advertising or analytics.

Storage

Tokens are stored encrypted as GitHub Actions secrets in the operator's private repository. Video scripts, rendered videos and an upload log (publish ID, status, date, caption) are stored in that repository. No other personal data is collected and this website does not use cookies or trackers.

Retention and deletion

You can revoke access at any time in TikTok (Settings and privacy → Security → Manage app permissions). Revoking access invalidates the tokens; you can also request deletion of any stored data by contacting us.

Third parties

Data is processed only by TikTok (to receive the uploads) and GitHub (to run the scheduled jobs and store the repository).
